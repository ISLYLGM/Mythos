# ☕ Mythos

> Um aplicativo de café temático inspirado em mitologias brasileiras e de diferentes partes do mundo. ☕✨

## 📖 Sobre o projeto

O **Mythos** é um aplicativo desenvolvido como projeto acadêmico, unindo a experiência de um café temático com o universo das mitologias.

A proposta é criar uma experiência diferente para os usuários, apresentando elementos de diversas culturas e mitologias de forma interativa e acessível.

## 🏛️ Mitologias

O projeto tem como inspiração diferentes tradições mitológicas, incluindo:

- 🇬🇷 Mitologia Grega
- 🇪🇬 Mitologia Egípcia
- 🇯🇵 Mitologia Japonesa
- ⚔️ Mitologia Nórdica
- 🌎 Mitologias de diferentes partes do mundo


## 🎓 Projeto acadêmico

Este aplicativo foi desenvolvido como parte de um projeto acadêmico, com o objetivo de aplicar conhecimentos de desenvolvimento mobile, design de interfaces, programação e acessibilidade.
